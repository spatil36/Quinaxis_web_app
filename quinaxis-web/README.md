# Quinaxis Website

Files:
- `index.html`
- `styles.css`
- `script.js`
- `assets/quinaxis-logo.jpeg`

## Run locally
Open `index.html` in your browser, or run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages
Upload the contents to your repository and configure GitHub Pages to publish the folder containing `index.html`.

## Before production
Replace:
- `hello@quinaxis.com` if needed
- Loqsy `href="#"` with the actual Loqsy URL
- Privacy Policy / Terms links
- company copy and legal company name once finalized
